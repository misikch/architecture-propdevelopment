На [схеме](PropDevelopment_С4_model_task3.drawio.xml) представлена интеграция с двумя новыми
сторонними сервисами "Интеллектуальный шлагбаум" и "Интеллектуальный домофон". 
После доработок клиентов и бека становится доступен новый функционал управления вбъездом и выездом, 
а также управление дверью через домофон.

Требования к интеграции и сервисам:
- Передача данных осуществляется по защищенному соединению HTTPS (TLS 1.3)
- Соответствие 152 ФЗ "О персональных данных":
  - Получение явного согласия пользователей на обработку биометрических данных
  - Обеспечение защиты персональных данных при передаче и хранении
  - Возможность отзыва согласия на использование биометрии
  - Предоставление пользователям информации о целях и методах обработки их данных
  - Хранение биометрических шаблонов в зашифрованном виде
- Из нашей системы передаем только минимально необходимую и достаточную информацию для осуществления функций интегрированных систем:
  - Для домофона: биометрические шаблоны лиц и идентификаторы авторизованных пользователей
  - Для шлагбаума: номера автомобилей с разрешенным доступом
- Аудит действий и событий:
  - Ведение подробных журналов всех операций доступа (время, пользователь, тип доступа)
  - Регистрация всех попыток входа, включая неудачные
  - Настройка оповещений о подозрительной активности
  - Хранение логов не менее 3 месяцев для возможности расследования инцидентов
- Авторизацию сделаем через OAuth 2.0
- Многофакторная аутентификация (MFA):
  - Реализуем по возможности обязательное использование MFA при добавлении новых пользователей в систему доступа
  - Второй фактор включаем при изменении настроек доступа (SMS/email/push-notification)
  - Дополнительное подтверждение при настройке автоматического открытия для новых лиц/номеров
- Запросы и ответы происходят с беком, через `tenant-core-app`
- Хорошо было бы убедиться, что внешние системы не хранят данные пользователей (см. пункт с соответствием 152 ФЗ). 
- Рекомендуется также проведение периодического аудита безопасности интеграции и тестирования на проникновение для выявления потенциальных уязвимостей.)
