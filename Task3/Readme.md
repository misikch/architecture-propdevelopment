На [схеме](PropDevelopment_С4_model_task3.drawio.xml) представлена интеграция с двумя новыми
сторонними сервисами "Интеллектуальный шлагбаум" и "Интеллектуальный домофон". 
После доработок клиентов и бека становится доступен новый функционал управления вбъездом и выездом, 
а также управление дверью через домофон.

Требования к интеграции и сервисам:
- Передача данных осуществляется по защищенному соединению HTTPS (TLS 1.3)
- Из нашей системы передаем только минимально необходмую и достаточную информацию для осуществления фукнций интегрированных систем
- Авторизацию сделаем через OAuth 2.0
- Запросы и ответы происходят с беком, через `tenant-core-app`
- Хорошо было бы убедиться, что внешние системы не хранят данные пользователей. 
Но все может измениться в процессе доработок на их стороне, поэтому см. п.2
